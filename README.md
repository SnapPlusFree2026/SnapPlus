# Petit site de pseudo

## Fichiers
- `index.html` : page principale
- `success.html` : page après validation
- `style.css` : design
- `script.js` : envoi Discord + redirection

## Configuration
Ouvre `script.js` et remplace :

COLLE_TON_WEBHOOK_ICI

par ton webhook Discord.

## Hébergement GitHub Pages
1. Crée un repository public sur GitHub.
2. Ajoute les 4 fichiers + ce README.
3. Va dans Settings > Pages.
4. Source : Deploy from a branch.
5. Branch : `main` et dossier `/ (root)`.
6. Enregistre et attends quelques instants.

Ton site sera accessible avec une adresse du type :
https://TON-PSEUDO.github.io/NOM-DU-REPO/
